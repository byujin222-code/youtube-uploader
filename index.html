YouTube Auto Uploader

개인용 방송 다시보기 자동 업로드 프로그램 · Personal VOD auto-upload tool

이 프로그램은요

백유진이 자기 컴퓨터에서만 쓰는 개인용 프로그램이에요. OBS로 녹화한 방송 영상을 날짜 이름으로 정리하고, 본인 소유의 유튜브 채널에 일부공개로 올려요.

This is a personal desktop tool used only by its owner. It renames OBS stream recordings by date and uploads them as unlisted videos to the owner's own YouTube channel. It is not offered to other users.

개인정보처리방침 · Privacy Policy

이 프로그램은 YouTube Data API를 통해 아래 권한만 사용해요.

  • 사용 권한: https://www.googleapis.com/auth/youtube — 본인 채널에 영상 업로드, 올린 영상의 제목 수정, 채널 이름 확인
  • 저장: 구글 로그인 토큰은 사용자 본인 컴퓨터의 프로그램 폴더에만 저장돼요. 다른 서버로 보내지 않아요.
  • 공유: 어떤 데이터도 제3자에게 팔거나 공유하지 않아요. 광고나 분석에 쓰지 않아요.
  • 삭제: 프로그램 폴더의 token.json을 지우거나 구글 계정의 앱 권한에서 접근을 해제하면 바로 끊겨요.

The app uses the YouTube Data API scope https://www.googleapis.com/auth/youtube only to upload videos to the owner's channel, edit the titles of those uploads, and read the channel name. OAuth tokens are stored only on the owner's local computer and are never transmitted to any other server. No data is sold, shared with third parties, or used for advertising or analytics. Access can be revoked at any time by deleting the local token file or at Google Account permissions.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
